# Extra Stash Gear — exact authored regular weapon removal (2026-10-18)

**Trigger:** `loot.stashGearEnabled=true`. The switch alone removes **13 audited ordinary authored weapon item entries** from `GameData/ItemGeneratorPrototypes.cfg` using indexed `removenode` BPatch, irrespective of all six bonus-gear strengths. When OFF the feature emits **zero** removal entries. Bonus gear remains separately rank-gated and nondeterministic.

**Authority:**
- Original 45-row authored-equipment snapshot: `docs/generators/stash-gear-unique-randomization-backlog.csv`, of which 14 rows have `FuturePool=WEAPON`.
- Exact immutable 13-entry target file: `src/TrueCustomDifficulty/Data/stash-authored-weapon-removal-manifest.csv`. The file includes original ActorSID, GeneratorSID, ItemPrototypeSID and `ItemGenerator/[1]/PossibleItems/[0]` path for each target.
- Cross-validation: each of the 13 is present as `REGULAR_SMARTLOOT` in the physical stash safety catalog; each is present as the same weapon SID in the independently audited `world-weapon-shuffle-manifest.csv`. Writer additionally checks all 13 against the current no-clue `smartloot-regular-world-actor-manifest.csv` and `base-stash-protected-actor-manifest.csv`.

**Not removed:** `Gun_Trophy_AR` in `Promzona_StorageontheHill_StashGenerator2_1CBBBE...` has not been classified as safely ordinary; it remains in-game. The `STCMalachite__StashGenerator_464E8...` with `GunGrim_ST` is source-protected even though it appears in the World Weapon Shuffle's existing slot catalog: Extra Gear does not touch it. Other quest, named-clue, special, unique and unclassified stash populations are all excluded. The physical `SpawnActorPrototypes.cfg` stash ActorSIDs, any direct world weapons, SmartLoot, medicines, ammunition, non-weapon authored sibling categories, separate attachments and suits are unchanged. Nested attachments/upgrades belonging to a *removed weapon item* disappear together with that item node, as intended.

**Interaction with World Weapon Shuffle:** Both features touching the same fixed generator source slots would invalidate shuffle's distribution/multiplicity guarantees. Rather than silently patch conflicting fields, `CfgPatchWriterService` raises a clear `InvalidDataException` when both toggles are on. Disable either feature for a valid build. Non-conflicting World Placement controls are independent.

**Meaning of controls:** Basic, Standard, Rare each exposes independent WEAPONS and ARMOR strengths: OFF = no new category; RARE = `Chance 0.02`; MOD = `Chance 0.07`; FREQ = `Chance 0.15`. Values apply to a newly authored per-rank eligible item entry, **not** to the removal, physical stash appearance or item count. Up to one weapon entry and one suit entry is emitted for each eligible source category. PlayerRank gate and item-tier cap remain intact. A physical stash may consume multiple generator sources, so no global 0–2 guaranteed count is claimed.

**QA contracts:** `python3 tools/audit_extra_stash_gear.py` matches all 13 identities and exact node paths to the source, checks both protected exclusions, and checks the production writer wiring. `tests/LootSpecialGeneratorsContract/StashGearRemoval.cs` verifies generated patches include exactly 13 removable item nodes with the checkbox ON (all strengths OFF), none with it OFF, and fail-closed behavior for World Weapon Shuffle. The original scalar/medical/SmartLoot tests remain independent. No claim of local build, Wine or in-game validation until those are executed. Test ungenerated, unopened stashes in-game; existing saved stash contents may have been generated before the mod was applied.
